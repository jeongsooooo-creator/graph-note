# 그래프 노트

함수와 관계식을 입력하면 그래프를 실시간으로 그려주는 한국어 웹 앱입니다. HTML, CSS, JavaScript만 사용하며 설치나 빌드가 필요하지 않습니다.

## 실행

`index.html`을 브라우저에서 열면 사용할 수 있습니다. 정적 웹 호스팅에도 파일을 그대로 올릴 수 있습니다.

## 주요 기능

- 여러 수식을 색상별로 표시하고 개별 표시/숨기기
- 수식 예시 및 간편 수식 키보드
- 곱셈 기호 생략: `2x+1`, `2(x+1)`
- 함수: `x^2`, `y=sin(x)`, `sqrt(x)`, `abs(x)`, `ln(x)`, `log(x)`
- 관계식: `x^2+y^2=9`, `x=2`
- 매개변수 `a` 슬라이더
- 드래그 이동, 스크롤 및 버튼 확대/축소
- 그래프 PNG 저장 및 브라우저 내 수식 자동 저장
- 모바일 화면 대응

## 입력 안내

거듭제곱은 `^` 또는 `²`, `³`을 사용합니다. 함수의 인수는 `sin(x)`처럼 괄호로 감쌉니다. `π`, `pi`, `e`를 지원합니다. 삼각함수는 라디안 단위이며 `log`는 밑이 10인 로그, `ln`은 자연로그입니다.

관계식은 수치 근사로 그리므로 매우 작은 도형이나 특이점, 부호가 바뀌지 않는 중근 관계식은 표시되지 않을 수 있습니다. 부등식 및 매개곡선은 지원하지 않습니다.

## 파일

- `index.html`: 화면 구성
- `style.css`: 반응형 디자인
- `app.js`: 수식 파서, 그래프 렌더링 및 조작

외부 JavaScript 라이브러리는 사용하지 않습니다. 글꼴은 Google Fonts에서 불러오며 연결되지 않으면 기본 글꼴을 사용합니다. 수식은 브라우저에서 계산됩니다.
